[#netz-first_packet]
== netz::first&lowbar;packet

Locate the first complete packet at the start of the buffer&period;

=== Synopsis

Declared in `&lt;netz&sol;stream&period;hpp&gt;`

[source,cpp,subs="verbatim,replacements,macros,-callouts"]
----
link:#netz-buffer_view[buffer&lowbar;view]
first&lowbar;packet(link:#netz-buffer_view[buffer&lowbar;view] input);
----

=== Description

Scans `input` for a frame boundary&period; The returned view aliases the same memory as `input`, so the storage behind `input` must outlive the returned view&period;

=== Return Value

A view of the bytes belonging to the first packet, or an empty view if no complete packet is present yet&period;

=== Parameters

[cols="1,4"]
|===
| Name| Description
| *input*
| Bytes received from the stream, up to the caller&apos;s current fill mark&period;
|===
