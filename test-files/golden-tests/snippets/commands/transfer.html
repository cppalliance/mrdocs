Reference

transfer

Moves funds from one account to another.

Synopsis

Declared in <transfer.cpp>
void
transfer(
    int from,
    int to,
    long amount);

Exceptions

Name Thrown on
std::invalid_argument If an account number is unknown.
std::out_of_range If from cannot cover amount.

Preconditions

  • amount is positive.
  • from and to are different accounts.

Postconditions

  • from falls by amount and to rises by the same.
