[#app-add]
== app::add

Add two integers&period;

=== Synopsis

Declared in `&lt;arithmetic&period;hpp&gt;`

[source,cpp,subs="verbatim,replacements,macros,-callouts"]
----
int
add(
    int a,
    int b);
----

=== Description

Returns the arithmetic sum of the two arguments&period; The example lives in this comment and is exported to a file the build compiles, so it never falls out of date&period;

=== Example

[,cpp]
----
int s = app::add(2, 3);
assert(s == 5);
----
