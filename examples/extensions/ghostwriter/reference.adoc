[#app-Circle]
== app::Circle

A circle in the plane&period;

=== Synopsis

Declared in `&lt;simple&period;cpp&gt;`

[source,cpp,subs="verbatim,replacements,macros,-callouts"]
----
struct Circle;
----

=== Description

A `Circle` is defined entirely by its radius&semi; its center is supplied by the surrounding coordinate system rather than stored here&period; This keeps the type small enough to pass by value&period;

The radius is assumed non&hyphen;negative&period; Passing a negative radius is a precondition violation, not a runtime error, so the geometry helpers do not check for it&period;

[#app-Vec2]
== app::Vec2

A point or displacement in the plane&period;

=== Synopsis

Declared in `&lt;simple&period;cpp&gt;`

[source,cpp,subs="verbatim,replacements,macros,-callouts"]
----
struct Vec2;
----

=== Description

A `Vec2` stores a pair of Cartesian coordinates and doubles as both a point and a displacement&period; Arithmetic on it follows the usual rules for a 2&hyphen;D vector space, so adding two vectors adds their components and scaling multiplies them&period;

Prefer `Vec2` over a bare `std&colon;&colon;pair&lt;double, double&gt;` when the values are geometric&colon; the named `x` and `y` members and the geometry helpers make intent obvious at the call site, and keep unrelated pairs from being mixed in by mistake&period;

[#app-distance]
== app::distance

The distance between two points&period;

=== Synopsis

Declared in `&lt;simple&period;cpp&gt;`

[source,cpp,subs="verbatim,replacements,macros,-callouts"]
----
double
distance(
    link:#app-Vec2[Vec2] const& a,
    link:#app-Vec2[Vec2] const& b);
----

=== Description

`distance` returns the Euclidean distance between two points&colon; the length of the straight segment joining them, or equivalently the square root of the summed squared differences of their `x` and `y` components&period;

The value is symmetric in its arguments and is zero exactly when the two points coincide, so it works well as the basis for an equality&hyphen;with&hyphen;tolerance check&period;

=== Return Value

The straight&hyphen;line distance between `a` and `b`&period;

| *a*
| The first point&period;
| *b*
| The second point&period;
