=== Description

Wraps an https://example.org/docs/other/socket.html[`other&colon;&colon;socket`], which another documentation set covers, and is closed with https://example.org/docs/other/socket/close.html[`other&colon;&colon;socket&colon;&colon;close`]&period; One is opened by https://example.org/docs/other.html#a1b2c3[`other&colon;&colon;connect`], which that set documents on the page of the namespace holding it, while https://example.org/docs/elsewhere.html[`elsewhere`] is a namespace of it with a page of its own&period;
