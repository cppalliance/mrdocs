=== Description

The roots are stem:[x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}]&period;

A standalone Markdown display span is promoted to a block&colon;

[stem]
++++

++++

[stem]
++++
e^{i\pi} + 1 = 0
