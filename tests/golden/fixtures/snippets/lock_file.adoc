== lock&lowbar;file

Lock a file for exclusive access&period;

=== Synopsis

Declared in `&lt;lock&lowbar;file&period;hpp&gt;`

[source,cpp,subs="verbatim,replacements,macros,-callouts"]
----
&lsqb;&lsqb;nodiscard&rsqb;&rsqb;
&sol;&ast; implementation-defined &ast;&sol;
lock&lowbar;file(std::filesystem::path const& path);
----

=== Description

The lock is held until the returned object is destroyed&period;

=== Exceptions

[cols="1,4"]
|===
| Name| Thrown on
| `std&colon;&colon;system&lowbar;error`
| If the file cannot be locked&period;
|===

=== Return Value

An object that holds the lock&period;

[NOTE]
====
The return value https://en.cppreference.com/cpp/language/attributes/nodiscard[should not be discarded^].
====
=== Parameters

[cols="1,4"]
|===
| Name| Description
| *path*
| The path of the file to lock&period;
|===
