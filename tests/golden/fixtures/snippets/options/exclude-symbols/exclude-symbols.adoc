[#jzon-validate]
== jzon::validate

Validate that the document is well&hyphen;formed JSON&period;

=== Synopsis

Declared in `&lt;jzon&sol;parser&period;hpp&gt;`

[source,cpp,subs="verbatim,replacements,macros,-callouts"]
----
bool
validate(char const* source);
----

=== Description

Parses `source` without constructing a value tree, reporting only whether the input conforms to RFC 8259&period; Comments and trailing commas are rejected&period;

=== Return Value

`true` if the document is syntactically valid JSON, `false` if any syntactic error is encountered&period;

=== Parameters

[cols="1,4"]
|===
| Name| Description
| *source*
| A null&hyphen;terminated UTF&hyphen;8 JSON document&period;
|===
