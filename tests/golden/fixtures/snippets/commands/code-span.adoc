== set&lowbar;value

Sets the value pointed to by `target`&period;

=== Synopsis

=== Description

The previous value of `&ast;target` is overwritten&period; The HTML form `&ast;target` and the Doxygen `new&lowbar;value` command render the same way as the Markdown backticks&period;
