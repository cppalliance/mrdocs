== netz::buffer&lowbar;view

A non&hyphen;owning view of a contiguous byte range&period;

=== Description

Used as the parameter and return type for the framing helpers in `netz&colon;&colon;stream` and as the buffer surface presented to async read handlers&period; Stores a pointer and a length, and does not extend the lifetime of the storage it refers to&period;
