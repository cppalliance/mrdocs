= Reference
:page-aliases: extensions/dom-reference.adoc, generators/dom-reference.adoc, generators/schema.adoc

This is the reference for the data MrDocs extracts into a cpp:Corpus[corpus] and exposes to each generator as structured objects: each cpp:Symbol[symbol], and the types, names, template parameters, and documentation blocks attached to it.

Machine-readable schema files for the corpus are also attached to this site: a xref:attachment$schemas/generators/mrdocs.rng[RELAX NG schema] for the XML representation and a xref:attachment$schemas/generators/mrdocs.schema.json[JSON Schema] for the JSON representation. In both, each definition is named after the MrDocs type it describes, such as `FunctionSymbol`. When two types share a name, each is qualified with as many enclosing scopes as it takes to tell them apart, joined with `.`: two types named `Text` in namespaces `a` and `b`, for instance, would get `a.Text` and `b.Text`. A name that one of the schema's fixed definitions already uses, such as `Tagfile`, is qualified the same way. A type for which no such name is free keeps a definition named `S_` followed by its symbol ID.
