= Inline Commands

An inline command works inside a sentence. Most shape a run of text, such as emphasis or a code span; the rest build links, cross-references, or pull documentation in from another symbol.

== Text formatting

MrDocs reads the usual Markdown spans, with Doxygen and HTML equivalents alongside them:

* xref:commands/reference.adoc#cmd-emphasis[Emphasis]: `+*text*+` or `+_text_+`.
* xref:commands/reference.adoc#cmd-strong[Strong]: `+**text**+` or `+__text__+`.
* xref:commands/reference.adoc#cmd-code-span[Code span]: `+`text`+`.
* xref:commands/reference.adoc#cmd-strikethrough[Strikethrough]: `+~~text~~+`.
* xref:commands/reference.adoc#cmd-highlight[Highlight]: `+==text==+`.
* xref:commands/reference.adoc#cmd-subscript[Subscript]: `+~text~+` or `+<sub>text</sub>+`.
* xref:commands/reference.adoc#cmd-superscript[Superscript]: `+^text^+` or `+<sup>text</sup>+`.

== Cross-references

xref:commands/reference.adoc#cmd-cross-reference[`@ref`] links to another symbol by its qualified name; MrDocs resolves it against the corpus and emits a working link. This is the command to reach for whenever one symbol's documentation should point at another.

== Copying documentation

When two symbols share documentation, xref:commands/reference.adoc#cmd-copy[`@copydoc`] copies the whole comment from another symbol; `@copybrief` and `@copydetails` copy just the brief or just the description. This keeps overloads and wrappers in step with a single source of truth.
