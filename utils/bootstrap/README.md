# utils/bootstrap

The tool that sets up a MrDocs development environment: it checks the required tools and compilers, fetches and builds the third-party dependencies from the JSON recipes in `recipes/`. It then writes `CMakeUserPresets.json` and the run configurations for CLion, VSCode and Visual Studio.

How to run the tool, its environment variables and its options are at https://mrdocs.com/docs/mrdocs/develop/bootstrap.html. How a run goes, the recipes, the project structure, the tests and troubleshooting are at https://mrdocs.com/docs/mrdocs/develop/contribute/utilities/bootstrap.html
